# Caspian Eye — Kura Delta pilot

Radar monitoring of water, wetlands and coastline change on Azerbaijan's Caspian coast, built for the
2026 NASA International Space Apps Challenge (challenge: *Dancing with the SARs*).

**Live demo:** https://ceye.online · **Demo video (30 s):** https://ceye.online/demo.mp4

## What it does
- Audits NISAR L2 GCOV coverage over the pilot area (NASA CMR): 115 products on 4 tracks.
- Reads the Kura Delta window from NISAR GCOV HDF5 files by byte range (no full 1.4 GB download),
  reprojects HH/HV γ⁰ to a 20 m UTM 39N grid and maps open water with a per-scene two-class model.
- Maps water from Sentinel-1 RTC for every October 2017–2026 and monthly in 2026.
- Computes change, area (km²) and confidence for three pilot zones; validates against Sentinel-2 (NDWI).
- Publishes everything as a static web page (`web/`) with map layers, time-lapse and an explanation panel.

## Key results (Oct 2017 → Oct 2026)
- 282 km² that was water in Oct 2017 was dry land in Oct 2026 (218 km² of it dry for 2+ Octobers).
- Open water in the Qızılağac Bay pilot zone (around Ramsar site 1076): 521 → 391 km² (−25%).
- Radar vs Sentinel-2 optical water: 90–97% pixel agreement. NISAR vs Sentinel-1: 87–96%, aligned to within one 20 m pixel.
- 2026 season, area imaged by NISAR on all 10 dates: both sensors show open water falling from June to October.

## Pipeline
| Step | Script |
| --- | --- |
| NISAR coverage audit | `scripts/audit.py`, `scripts/nisar_browse.py` |
| Sentinel-1 / Sentinel-2 download (Planetary Computer) | `scripts/fetch_s1b.py`, `scripts/fetch_s2.py` |
| Sentinel-1 analysis, change, validation | `scripts/analyze.py` |
| Stable reference areas | `scripts/build_stable.py` |
| NISAR GCOV download (byte range) | `scripts/fetch_nisar_gcov.py`, `scripts/h5open.py` |
| NISAR classification and statistics | `scripts/nisar_classifier.py`, `scripts/analyze_nisar.py` |
| Display images and time-lapse | `scripts/render_nisar_rgb.py`, `scripts/make_media.py`, `scripts/make_hero.py` |
| Publish the web page (nginx) | `scripts/deploy_site.sh` |

Pilot zones are in `zones.json`. Raw rasters are not in the repository; the scripts re-download them.

## Running
```
python -m venv venv && venv/bin/pip install -r requirements.txt
# NISAR access needs a free NASA Earthdata token in ~/.earthdata_token (or EARTHDATA_TOKEN_FILE)
```
The analysis needs about 2.5 GB RAM.

## Limitations
One NISAR track so far, mostly Provisional products; false water on smooth farmland; the flooded-vegetation
signal is weak and not separated from buildings; one scene per year for the long-term trend.

## Data and credits
NISAR L2 GCOV: NASA–ISRO, distributed by the ASF DAAC. Contains modified Copernicus Sentinel data 2017–2026,
accessed through the Microsoft Planetary Computer.

## Use of AI
This project was built with the help of AI. An AI assistant (Claude, by Anthropic) wrote most of the processing
code and the web page, proposed the classification method, drafted the text and produced the demo video and its
synthesized soundtrack. The team defined the concept and the pilot area, set up NASA Earthdata access, reviewed
the results and chose what to present. All maps and numbers come from running this code on the data listed above;
none was generated by an AI model.
